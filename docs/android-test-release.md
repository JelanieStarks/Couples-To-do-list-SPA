Download **Couples2Do-Test.apk** below on each Android phone. This is a prerelease for hands-on testing, not a Google Play release. This public repository's downloads are publicly accessible.

## Install

1. Download the APK from Assets, then open it from Downloads.
2. If Android asks, allow this browser or file manager to install this APK. You can turn that permission off afterward.
3. Open **Couples2Do Test**. Android 7.0 or newer is required.
4. Sign in with your own account on each phone. New accounts may need email confirmation before signing in.
5. In Partner settings, use one person's invite code on the other phone. Reopen the app on the first phone if the partner name has not refreshed.

The test app uses a separate application ID, so you can keep your older app installed. Local data from the older app will not transfer automatically. Keep it installed until you have checked anything you want to retain.

## Try together

* Create a task on one phone and check that it appears on the other.
* Edit and complete tasks from both phones, then close and reopen the app to check persistence.
* Try a Life Meeting and save notes. For this first test, take turns editing the same meeting; simultaneous edits are not conflict-safe yet.
* Check the calendar, text size, keyboard, and navigation on both phones.
* Routines are currently stored locally and do not sync between phones.

The APK is signed with a dedicated test key, reused for later test updates. Signing and automated checks do not replace testing on your actual phones. Report the screen, steps, expected result, actual result, and phone model for anything that fails.
